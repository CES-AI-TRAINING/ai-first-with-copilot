# Zero-shot Prompting

Description: Use a direct instruction without examples. Good for short, well-specified tasks.

Prompt:

```
System: You are a concise assistant.
User: Translate the following sentence to French in one sentence:
"{sentence}"
```

Example input: "Open the file and print the first line." 

Expected output (example): "Ouvrez le fichier et imprimez la première ligne."
